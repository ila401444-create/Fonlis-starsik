# Fonlis Stars — Godot Android project

Проект для загрузки в GitHub и автоматической сборки APK через GitHub Actions.
Это оригинальный фан-проект в духе мобильных аренных шутеров. В проекте нет официальных ресурсов Brawl Stars.

## Как загрузить
1. Создай пустой репозиторий GitHub.
2. Распакуй этот ZIP и загрузи **содержимое** архива в корень репозитория (папка `.github` тоже должна быть в корне).
3. Открой вкладку **Actions** и разреши запуск workflows, если GitHub попросит.
4. Открой workflow **Build Android APK** и нажми **Run workflow**. Также сборка запускается при push в `main` или `master`.
5. После завершения открой запуск workflow → **Artifacts** → скачай `FonlisStars-debug-apk`.

## Важно
- Для APK не нужно устанавливать Godot, Termux или Android Studio на телефон: сборка идёт на GitHub.
- Если Actions упадёт, открой лог красного шага — причина будет там. Разные версии Android SDK/Godot могут требовать настройки экспорта.
- Это игровой проект, а не готовый коммерческий релиз. Управление адаптировано для сенсорного экрана.
- Все имена/визуальные элементы в этом архиве — оригинальные фанатские заготовки; официальные персонажи, логотипы и ресурсы не включены.

## Управление в бою
- Левый круг: движение.
- Кнопка ATTACK: выстрел в сторону ближайшего противника.
- Кнопка SUPER: мощная атака по области.
- На ПК для проверки: WASD/стрелки, Space — атака, E — супер, Esc — назад.
